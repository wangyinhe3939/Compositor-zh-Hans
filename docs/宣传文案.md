# Compositor 简体中文版

**让图像创作，说中文。**

汉化维护：**Double One DD**

## 简介

Compositor 简体中文版，是基于开源 Compositor 制作的 macOS 原生图像编辑器汉化版本，由 Double One DD 独立维护。它围绕图像合成与照片后期，提供图层、蒙版、选区、画笔、文字、调色和滤镜等工具。本次汉化包含 1,235 条中文资源，覆盖界面、帮助提示、消息与系统说明，并保留英文回退。适合希望用中文进行图片合成与修图的 Apple 芯片 Mac 用户。

## 可直接分享的文案

把图像创作，放回熟悉的中文语境。

我为开源 macOS 图像编辑器 Compositor 制作了简体中文版：从菜单、工具和图层面板，到帮助、错误提示与操作名称，整理了 1,235 条中文资源，并修正了实际使用中发现的中文截断和动态名称漏译。

你可以继续使用原有的图层、蒙版、混合模式、画笔、文字与调色工具，也能按自己的需要修改源码。原项目由 Robbie Tilton / Wonder Assembly 开发，本分支由 Double One DD 负责汉化维护，保留 MIT 许可与原作者署名。

适用环境：macOS 26.0 及以上，Apple 芯片 Mac。已提供 DMG 和 ZIP 安装包，无需 Xcode。社区包使用 ad-hoc 签名，尚未经过 Apple 公证；首次打开请按安装说明处理系统提示。
