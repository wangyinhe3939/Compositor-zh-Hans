# Compositor 简体中文版 1.5 · 汉化发行 1

汉化维护：**Double One DD**

基于 Compositor 1.5 的首个简体中文社区安装包，App 构建号为 **47**。

## 下载

- **推荐：** `Compositor-1.5-zh-Hans.1-arm64.dmg`，打开后把 App 拖到 Applications。
- **备用：** `Compositor-1.5-zh-Hans.1-arm64.zip`，解压后把 App 拖到“应用程序”。
- **校验：** `SHA256SUMS.txt`，包含两个下载包的 SHA-256。

适用 **macOS 26.0 及以上、Apple 芯片 Mac**。无需 Xcode，Intel Mac 不适用。

## 汉化与修正

- 1,235 条简体中文资源，覆盖界面、帮助、消息和系统说明，保留英文回退。
- 补齐涂抹、液化的撤销名称与 PSD 默认图层名称翻译。
- 修正画布尺寸说明的中文截断。
- 使用优化的 Release 构建，移除调试产物并映射本机构建路径。
- 停用上游自动更新入口；“检查更新…”打开本仓库的 Releases 页面，避免覆盖汉化。

## 签名与首次打开

**本包使用 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证。** 首次打开可能出现 macOS 安全提示。确认来源、校验文件并信任项目后，可按照 [安装说明](https://github.com/wangyinhe3939/Compositor-zh-Hans/blob/main/docs/安装说明.md)，在系统设置的“隐私与安全性”中为该 App 选择“仍要打开”。无需关闭系统整体安全检查。

本地启动与归档检查不代表已在其他 Mac 上完整验证，完整功能回归仍有待补充。PSD 默认图层名称修正已通过源码与构建核验，尚未单独完成真实 PSD 导入验收。
