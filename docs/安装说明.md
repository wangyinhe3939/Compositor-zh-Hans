# 安装 Compositor 简体中文版

汉化维护：**Double One DD**。原项目由 Robbie Tilton / Wonder Assembly 开发，使用 MIT 许可。

## 下载与安装

系统要求：**macOS 26.0 或更高版本，Apple 芯片（arm64）Mac**。Intel Mac 不适用；使用安装包无需安装 Xcode。

1. 打开 [GitHub Releases](https://github.com/wangyinhe3939/Compositor-zh-Hans/releases/latest)。
2. 下载以 `-arm64.dmg` 结尾的安装镜像。
3. 打开 DMG，将 `Compositor.app` 拖到 `Applications`（应用程序）。已有 Compositor 时，先退出 App，再按需替换；请自行保留重要工程文件。
4. 从“应用程序”打开 Compositor。

也可下载 `-arm64.zip`，解压后将其中的 `Compositor.app` 拖入“应用程序”。ZIP 与 DMG 中的 App 来自同一次 Release 构建。

本分支保留原 App 的 Bundle ID，安装到同名位置时会替换原版。它不是可与同名原版完全隔离运行的第二套 App。

**这是 ad-hoc 签名的社区发行包，没有 Developer ID 发行签名，也未经过 Apple 公证。** macOS 首次打开时可能提示无法验证开发者或无法检查恶意软件；签名完整性检查不能替代 Apple 公证或身份认证。

如果你已确认下载来自本仓库、核对文件完整性并信任该项目，可先尝试打开一次，再进入 **系统设置 → 隐私与安全性**，找到该 App 的“仍要打开”按钮并确认。此方式只为选定 App 添加例外，不需要关闭系统整体安全检查。

具体提示与组织管理限制可能因系统设置而不同，请参考 [Apple 官方说明：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。如果系统报告 App 已损坏或包含恶意内容，请停止安装，重新下载并反馈，不要把所有警告都当作未公证提示。

## 选择简体中文

App 跟随系统语言。在 **系统设置 → 通用 → 语言与地区 → 应用程序**中，将 Compositor 设置为“简体中文”，然后退出并重新打开。英文仍可作为回退语言。

## 更新

本次社区发行包不会启动上游 Sparkle 自动更新器。“检查更新…”会打开本汉化仓库的 GitHub Releases 页面；下载新包后手动替换 App。

## 核对下载文件

Release 附带 `SHA256SUMS.txt`。将它与下载的安装包放在同一文件夹，在该文件夹中执行：

```bash
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
```

校验值用于检测下载内容是否一致，不能证明发布者身份。请同时确认下载页面是 `wangyinhe3939/Compositor-zh-Hans`。
